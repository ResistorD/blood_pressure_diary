Как читать PolySyndicate

Это исследовательская система для поиска связок и потенциального арбитража на prediction-markets.

Основной поток

  • Рынки → база рынков и метаданных.
  • Сигналы → агент заметил аномалию/связь.
  • Возможности → агрегированный кейс по рынку.
  • Решения → действие (вход/выход/наблюдать).
  • Позиции → paper-результат.

Коротко о смысле

  • Сигнал ≠ сделка. Это повод смотреть, а не входить.
  • «Наблюдать» — тоже решение.
  • Paper — без денег, но с дисциплиной.

Execution Guards

Автоматическая защита по spread/depth/book-age. Можно override удержанием кнопки.

Impact Guard

Блокирует сделки, если ожидаемый импакт (проскальзывание) превышает порог. Можно обойти удержанием кнопки.

Safe Size

Терминал показывает максимальный размер сделки, который укладывается в порог Impact Guard (VWAP‑based).
